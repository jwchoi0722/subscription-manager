# Subscription Manager

Track your Netflix, Spotify, Audible and all other subscriptions in one place. See how much you're spending and where.

Built with React, [FullCalendar](https://fullcalendar.io/), Vite and shadcn.

Currently a static site using localStorage.

## Setup & Run
Build
```bash
npm run build
```
Run
```bash
npm run dev
```
